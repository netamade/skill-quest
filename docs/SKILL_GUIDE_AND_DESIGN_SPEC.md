# SKILL QUEST 機能追加仕様（スキルガイド／デイリー目標／デザイン刷新）

対象リポジトリ: netamade/skill-quest（GitHub Pages 静的サイト）
対象ファイル: index.html / engine.js / links.html（data.js の問題データは変更しない）

## 現状（前提）
- 収録ツールは5製品: Blue Prism（43問）/ ASTERIA Warp（46問）/ SmartDB（35問）/ PowerEgg（38問）/ Copilot Studio（34問）。
- 各製品の config に domains（分野）と objectives（学習目標）、judgement（判定）設定がある。
  判定ラベルは4段階: 未着手 / 挑戦中 / 安定 / マスター。閾値: マスター 0.85、安定 0.70、挑戦中 0.55。
- 学習記録は localStorage に保存され、再開機能がある。既存の記録形式は壊さないこと。

## 追加機能1: スキルガイド（弱点ガイド）
- 選択中ツールのホームに「スキルガイド」パネルを追加する。
- パネル上部に、そのツールの習熟サマリー（目標ごとのラベル内訳: マスター○件 / 安定○件 / 挑戦中○件 / 未着手○件）を表示する。
- その下に「あなたはまだここが足りません」として弱点リストを表示する。
  - 対象: ラベルが 安定 未満（挑戦中・未着手）の分野（domain）。並び順は弱い順（ラベル昇順 → 正答率の低い順 → 回答数の少ない順）。
  - 各行: 分野名、ラベルバッジ、正答率%、回答数/総問題数、「練習する」ボタン（その分野だけの練習をその場で開始できる）。
  - 弱点が無い場合は「弱点はありません。全分野が安定以上です」のような前向きな文面にする。
  - まだ1問も解いていない場合は「まずは1問解いてみましょう。解いた分野から弱点が見えてきます」のように案内する。
- 判定は既存の judgement 設定（閾値・window・decay・minEvidence）をそのまま使う。閾値や判定ロジックの意味は変えない。

## 追加機能2: デイリー目標（今日の最低ノルマ促進）
- ホームに「今日のチャレンジ」カードを追加する。
  - 今日の目標（解く問題数）をユーザーが選べる: 3 / 5 / 10 / 20 問。既定は5問。設定は localStorage に保存する。
  - 今日解いた問題数 / 目標 をプログレスリングまたはバーで表示する（練習・模試のどちらも数える）。
  - 連続達成日数（ストリーク）を表示する。
  - 文面: 未達なら「あと○問で今日の目標達成」、達成したら称賛文＋「もっと解く」導線。
  - セッション中に目標を達成した瞬間、一度だけ祝福メッセージ（トースト等）を出す。
- 日付判定は端末のローカル日付で行う。過去の記録に時刻情報が無い場合は、この機能の稼働開始日以降の回答から数えればよい（無理な推定をしない）。

## 追加機能3: デザイン刷新
- 方向性: 今風でユーザーフレンドリーな、明るく清潔感のあるカード型UI。
  - カードUI（角丸・柔らかい影・余白広め）、大きめのタップ領域（44px以上）、モバイルファースト。
  - ツールごとのアクセントカラーは config の theme.primary を使う。
  - 進捗はリング/バーで視覚化し、数字と併記する。
  - ヘッダーはツール切替が分かりやすい形に整理する。
  - 文字サイズと行間を読みやすくし、コントラストを確保する。
- 制約: 外部CDN・外部フォント・外部ライブラリは追加しない（オフラインでも動く現行構成を維持）。
  engine.js の既存ロジック（出題・判定・記録・再開）は壊さない。DOMの改修が必要な場合はロジック側も合わせて整合させる。
