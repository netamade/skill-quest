# 発注書：SKILL QUEST のツールメニューに「正規表現道場」への外部リンクを追加

2026-11-12、発注者：クロ。担当：Codex。
対象リポジトリ：netamade/skill-quest（現行6ツール・196問）。

## 目的
ツール切替メニュー（画面上部のタブ列）の末尾に、姉妹サイト「正規表現道場」への外部リンクを1つ追加する。これはツール切替ではなく外部サイトへのリンクとして実装する。

## 作業内容

### 1. リンクの追加（engine.js の header()）
- `header()` が生成する `<nav class="tabs">` の中、KT_DATA から生成されるタブボタンの**末尾**に、次のリンクを1つ追加する。
  - 表示名：「正規表現道場 ↗」（外部リンクであることが分かるよう末尾に ↗ を付ける）
  - リンク先：`https://netamade.github.io/regex-dojo/`
  - `target="_blank"`、`rel="noopener noreferrer"` を付ける（新しいタブで開く）
- data.js は変更しない。KT_DATA にダミーのツールを追加するような実装はしない。

### 2. 見た目（styles.css）
- リンクの見た目を他のタブボタンと揃える（並び・高さ・角丸・余白・フォント）。タブ列の中で浮かないこと。
- リンクは「選択中（.on）」の状態にはならない。通常のタブと同じホバー表現でよい。

### 3. 検証（実施して PR 本文に結果を書く）
- data.js が従来どおりで、6ツール・196問が維持されていること。
- ローカル表示で、タブ列の末尾に「正規表現道場 ↗」が出て、クリックすると正規表現道場が新しいタブで開くこと。
- 既存ツールの切替・練習の開始と回答が従来どおり動くこと。
