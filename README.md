# SKILL QUEST（非公式・学習用）

Blue Prism / ASTERIA Warp の知識テストサイトです。個人の学習用に作成した**非公式**の練習サイトで、Blue Prism社・ASTERIA社および各公式認定試験とは関係ありません。

## できること

- 分野別（各11分野）の練習問題：即時フィードバック付き、解説・出典URL付き
- 分野マップ：分野ごとの到達度（未着手→挑戦中→安定→マスター）を可視化
- Blue Prism：本番テスト（DEV01形式の模擬試験。サイト内目安は正答率70%で、公式の合格基準はスケールドスコア600です）
- ASTERIA Warp：横断テスト（公式認定試験がないため合格目安は表示しません）
- 学習記録はブラウザ内（localStorage）に保存され、JSONでエクスポートできます

画面再現問題は自作のモック画面を使用しており、実際の製品とはデザイン・レイアウトが異なります。
